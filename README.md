# Python 🐍

Repositório dedicado ao estudo da linguagem Python, focado na implementação de algoritmos, estruturas de dados e automação de tarefas.

## 📌 Conteúdos Presentes

Os scripts contidos neste repositório abrangem:

* **Fundamentos:** Sintaxe, tipos de dados e estruturas de controle.
* **Estruturas de Dados:** Listas, tuplas, dicionários e conjuntos.
* **Algoritmos:** Implementações lógicas e resolução de problemas.
* **Modularização:** Funções, módulos e pacotes.
* **Orientação a Objetos:** Classes, atributos e métodos.
* **Manipulação de Dados:** Leitura e escrita de arquivos (IO).
* **Tratamento de Erros:** Gestão de exceções e depuração.

* O repositório está organizado em categorias fundamentais de ciência da computação:

### 🏗️ Estruturas de Dados
* **Listas:** Sequencial Estática, Dinâmica Encadeada, Dinâmica Duplamente Encadeada e Encadeada Circular.
* **Pilhas e Filas:** Implementações Dinâmicas e Estáticas de Pilhas, Filas e Deques.
* **Prioridade:** Fila de prioridade utilizando Array Ordenado e Heap.
* **Avançadas:** SkipList e Tabela Hash.

### 🌳 Árvores e Grafos
* **Árvores Binárias:** Árvore Binária de Busca (BST), Árvore AVL e Árvore Rubro-Negra.
* **Grafos:** Algoritmos de busca e geração de Árvore Geradora.

### 🔍 Busca e Ordenação
* **Ordenação:** Diversos algoritmos de ordenação (Sorting Algorithms).
* **Busca:** Busca Sequencial e Busca Binária.
